Tens to hundreds of agents, one conversation

In June 2026, Anthropic introduced Dynamic Workflows for Claude Code: a research-preview capability that coordinates large numbers of AI agents within a single workflow. Instead of handling problems linearly, Claude decomposes a task, assigns subtasks to multiple parallel subagents — tens to hundreds simultaneously in one session — and synthesizes results after internal comparison and verification. Independent adversarial agents attempt to refute findings before they surface. The feature is available in research preview across the Claude Code CLI, Desktop, and VS Code extension for Max, Team, and Enterprise plans, and via the Claude API, Amazon Bedrock, Vertex AI, and Microsoft Foundry.

Who it's for: Engineers facing multi-hour, multi-day problems: large refactors, codebase-wide audits, migrations, and research-heavy changes

Key features

🔀 Dynamic orchestration

Claude generates workflows on demand from your objective — it plans the work, distributes tasks across specialized agents, and iterates until results converge. No manual agent-team configuration.

⚔️ Adversarial verification

Independent agents attempt to refute findings before results are surfaced — built-in cross-checking instead of trusting the first answer from a single agent.

🏃 Parallel subagents

Runs tens to hundreds of subagents simultaneously in one session, each with its own context window. One agent reads the codebase, another tests assumptions, another hunts bugs.

💾 Progress persistence

Interrupted jobs resume where they left off rather than restarting — workflows that take hours survive crashed sessions.

⚡ Ultracode mode

Enable the new ultracode setting and Claude decides automatically when a workflow-based approach is appropriate — or ask explicitly for a workflow.

🌐 Everywhere Claude runs

Research preview across CLI, Desktop, and VS Code extension; also accessible via the Claude API, Amazon Bedrock, Vertex AI, and Microsoft Foundry.

The honest take

✓ What works

  • Massive parallelism for problems too large for a single agent — hours of work compressed
  • Adversarial verification catches errors a single pass would miss
  • Progress persistence means interrupted runs resume, not restart
  • Works everywhere Claude Code runs, including Bedrock and Vertex AI

✗ What doesn't

  • Research preview — rough edges and evolving behavior expected
  • Requires Max, Team, or Enterprise plan — not available on lower tiers
  • Best value on genuinely large tasks; small changes do not need the orchestration overhead

Verdict

Claude Code Workflows formalizes what power users were already assembling by hand — and makes it dramatic. Decompose, parallelize, adversarially verify, resume: for multi-hour refactors, codebase audits, and migrations, it turns Claude Code from a pair-programmer into a coordinated engineering team. The research-preview label and plan gating are real caveats, but for teams on Max or Enterprise with big problems, this is the most consequential Claude Code feature since subagents.
