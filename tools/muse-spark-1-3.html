Muse Spark 1.3: Meta's biggest agentic jump yet

Muse Spark 1.3 is Meta Superintelligence Labs' September 2026 update to its flagship Muse Spark line, and Meta calls it the company's biggest jump yet on coding and agentic tasks. It is a proprietary multimodal reasoning model built specifically for long-running agentic, multi-agent and coding workflows: sustaining work across extended tasks, remembering what it has learned, and juggling multiple workflows inside a single long thread. Meta announced it September 2, 2026 with 75.4% on DeepSWE 1.1, 88.8% on Terminal-Bench 2.1, 59.4% on SWEAtlas CodeBase QnA and 98.5% on long-context retrieval, all inside a 1 million token context window. A muse-spark-1-3-max reasoning tier followed within days on Muse Code and the Meta Model API.

Who it's for: Developers building long-running agents and multi-agent systems, coders living in Muse Code, and teams already on the Meta Model API who want frontier-class agentic performance without switching vendors.

Key features

🤖 Long-horizon agentic work

Sustains extended tasks across multiple workflows in a single 1M-token thread — given an open-ended objective, it uses tools to generate its own context from messy sources, corrects gaps in its plan, and tracks what it has learned to produce a final deliverable.

💻 Frontier coding scores

75.4% on DeepSWE 1.1 end-to-end agentic software engineering and 88.8% on Terminal-Bench 2.1 — Meta's biggest year-over-year coding jump, closing hard on the Claude Code and Codex class of tools.

🧠 1M-token context with real recall

98.5% on long-context retrieval inside the full 1 million token window, so the multi-workflow threads it sustains actually remember their earlier turns.

🤝 Collaborative behavior

Trained to collaborate more actively with users — it asks clarifying questions mid-thread instead of barreling ahead, a real usability shift for open-ended objectives.

🔧 Harness-generalized training

Trained across a diverse set of agentic harnesses so it generalizes to various agent environments rather than overfitting one framework.

🔍 Max reasoning tier

Muse Spark 1.3 max is available on Muse Code and Meta Model API with materially stronger coding and agentic output than the high/xhigh tiers — Meta recommends max even if you've tried 1.3 high.

The honest take

✓ What works

  • Meta's biggest agentic and coding jump yet — DeepSWE 1.1 75.4% is a real frontier-class number
  • 1M-token context with 98.5% long-context retrieval — the long-horizon claim is benchmarked, not marketing
  • Sustains multi-workflow threads and asks clarifying questions instead of guessing
  • Priced the same as Muse Spark 1.2 — aggressive for the capability jump

✗ What doesn't

  • Ecosystem (tooling, evals, community) younger than Claude Code or OpenAI's stack

Verdict

Muse Spark 1.3 is the most consequential Meta model update of 2026 for anyone building agents. The agentic-coding numbers are genuinely close to the leaders now, and the 1M context with real recall plus collaborative question-asking make it a serious option for long-horizon agent work. If you're API-driven and benchmark-obsessed, Claude and GPT still win the top rows; if you want frontier agentic performance with Meta's distribution and pricing, 1.3 max is now worth benchmarking seriously.
