The honest take

Modal is the serverless platform that lets AI engineers run GPU workloads, deploy ML models, and scale APIs without touching infrastructure. Write Python, deploy with one command, and Modal handles the rest — auto-scaling GPUs, managing secrets, and serving traffic. Think of it as Vercel for AI workloads. Founded by MIT CSAIL alumni, Modal has become the default choice for teams that want to ship ML without hiring a platform engineer.

Who it's for: ML engineers, AI researchers, and indie hackers who need GPU compute without managing servers. Especially valuable for teams deploying fine-tuned models, running batch inference, or building AI APIs.

Key features

GPU Instant GPU access

Spin up A100s, H100s, or L40s in seconds. No queue, no provisioning. Pay only for the seconds you use.

Scale Auto-scaling to zero

Your service scales from zero to thousands of containers automatically. No cold starts on warm pools.

Python Python-native deploy

Deploy with @modal.function decorators. No Dockerfiles, no YAML, no Kubernetes. Just Python.

Storage Ephemeral & persistent storage

Fast shared volumes for datasets and model weights. Mount S3/GCS buckets directly.

Pros and cons

✓ What works

  • Pay-per-second pricing (no idle costs)
  • H100/A100 available without waitlist
  • 10x faster deploy than AWS SageMaker
  • Free tier includes GPU seconds monthly

✗ What doesn't

  • Vendor lock-in (Modal-specific decorators)
  • No SQL database built-in
  • Learning curve for non-Python devs
  • Cold starts can be 5-10s on first invocation

Verdict

Modal is the best serverless GPU platform in 2026. If you're an ML engineer tired of Kubernetes and Terraform, Modal lets you focus on the model. The per-second pricing means you never pay for idle GPUs. Start with the free tier — it's generous enough for most prototyping.
