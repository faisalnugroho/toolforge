The honest take

Instructor is a Python library that wraps OpenAI, Anthropic, Mistral, and any OpenAI-compatible API to return structured, validated output. Define your response shape as a Pydantic model, and Instructor handles the extraction, validation, and retry logic. It pioneered the 'extraction as a first-class concept' pattern that every LLM framework now copies. Small library, huge impact — if you're building any LLM pipeline, Instructor should be in your requirements.

Who it's for: Python developers building LLM pipelines, RAG systems, or AI agents who need reliable structured output from language models. Essential for production LLM applications.

Key features

Pydantic Pydantic-native

Define response schemas as Pydantic models. Instructor validates output automatically, retries on failure.

Multi-LLM Multi-provider support

Works with OpenAI, Anthropic, Mistral, Cohere, and any OpenAI-compatible endpoint.

Retry Smart retry logic

Automatic retries with exponential backoff when the LLM returns malformed output. Configurable max retries.

Mode Multiple extraction modes

JSON mode, function calling, or prompt-based extraction. Pick what works best for your model.

Pros and cons

✓ What works

  • Makes LLM output deterministic and type-safe
  • Works with 20+ LLM providers
  • Tiny dependency, no bloat
  • Excellent docs and examples

✗ What doesn't

  • Python-only (no JS/TypeScript)
  • Requires Pydantic v2 knowledge
  • Some providers need specific extraction mode
  • Complex nested schemas can confuse smaller models

Verdict

Instructor is the single most useful Python library for production LLM applications in 2026. If you're using Pydantic (and you should be), Instructor makes structured LLM output trivial. Install it today — you'll use it in every project.
