CodeMender: autonomous vulnerability scanning, exploit-verified fixes

CodeMender is Google DeepMind's AI agent for code security, announced alongside the $100M Fairwind program as a core element of Google AI threat defense. It takes a comprehensive approach: reactive, instantly patching newly disclosed vulnerabilities, and proactive, rewriting and securing existing code to eliminate entire classes of vulnerabilities. The workflow is scan → verify → remediate: it scans codebases for deep flaws that static tools and model-only scanning miss, verifies each finding with an executable exploit, then generates and tests a code fix delivered as a diff inside developer tools like VS Code — developers stay in the loop and decide what gets committed. In its first six months the team upstreamed 72 security fixes to open source projects, some as large as 4.5 million lines of code.

Who it's for: Security engineers and maintainers of critical open source projects, enterprise dev teams drowning in vulnerability backlogs, and anyone who wants exploit-verified findings instead of scanner noise.

Key features

🔍 Deep vulnerability scanning

A security-context harness finds memory corruption, injection, web security issues, cryptographic flaws and insecure data handling that static analysis and model-only scanning both miss.

🧨 Exploit-verified findings

Every vulnerability is verified with an executable exploit before it reaches you — no alert fatigue from unproven scanner hits.

🩹 Tested remediation diffs

Fixes are generated, tested, and delivered as code diffs directly in VS Code and existing developer workflows for review and approval.

🧬 Class elimination, not whack-a-mole

Proactive mode rewrites and secures vulnerable code patterns to eliminate entire vulnerability classes, not just individual instances.

🌐 8-language coverage

Supports C/C++, Go, Java, Python, Ruby, Rust and TypeScript — the languages that dominate critical infrastructure dependencies.

🏛️ Fairwind + Mandiant integration

Part of Google's $100M Fairwind program with Gemini 3.8 Flash Cyber, plus Wiz and Mandiant consulting inside Google AI threat defense.

The honest take

✓ What works

  • Exploit-verified findings kill scanner false-positive noise
  • 72 real security fixes already upstreamed to OSS projects — proven in production, not slideware
  • Fixes land as reviewable diffs in VS Code, so developers keep control of commits

Verdict

CodeMender is the most credible autonomous security-fixing agent shipped so far — the exploit-verification step and 72 upstreamed OSS fixes separate it from the avalanche of AI scanners that just list more CVEs. If you maintain critical infrastructure or a big OSS dependency chain, get on the access list; everyone else should watch the ramp toward general release, because this category is about to get crowded with weaker imitations.
