The biggest coding-agent benchmark jump of the summer

Released August 12, 2026, Grok 4.6 keeps the 500K context window and $2/$6 rate card of Grok 4.5 but moves the benchmarks that matter: DeepSWE v1.1 climbed from 54.0% to 65.9%, Terminal-Bench v3.0 from 15.7% to 26.0%, and the AA Intelligence Index rose from 56 to 61. A new xhigh reasoning level joined low, medium, and high, and it shipped as the default in Grok Build while landing in Cursor (all plans) and GitHub Copilot the same month.

Who it's for: Coding agents on a budget, long-horizon agent runs, and teams that want frontier coding performance without frontier output pricing.

Key features

Up from 54.0% on Grok 4.5 - one of the largest single-version agentic-coding jumps of 2026, alongside Terminal-Bench v3.0 at 26.0% (from 15.7%).

⚡ xhigh reasoning

A fourth reasoning level beyond the high default for the hardest passes - the launch emphasis is long-running agents and interactive visual projects.

Half a million tokens of context on the API (256K inside Cursor) with text and image input, text output.

🔌 Everywhere you code

Default in Grok Build; available in the xAI API, Cursor (all plans), GitHub Copilot, OpenRouter, Vercel, Cloudflare, and Microsoft Foundry.

🔁 Agent-native tooling

The honest take

✓ What works
