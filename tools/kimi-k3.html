The largest open-source model ever released

Moonshot AI released Kimi K3 on July 16, 2026, just ahead of the World AI Conference in Shanghai, and it instantly became the largest open-source model ever shipped: a 3T-class architecture around 2.8 trillion parameters with native vision and a 1M-token context window. Moonshot positions its performance as approaching the top of the market, and public leaderboards back that up - BenchLM scores K3 at 74.87/100, the best of any Moonshot model and enough to top the open-source rankings. The API is OpenAI-SDK compatible, priced at $3 per million input and $15 per million output, with cached input at $0.30. Complete model weights were scheduled for public release by July 27, 2026.

Who it's for: Developers who want frontier-adjacent capability from open weights they can eventually self-host, at mid-tier API prices

Key features

🤖 2.8T-parameter open 3T-class model

The largest open-source model ever released - complete weights announced for public release by July 27, 2026

📦 1M-token context window

A roughly 1M-token context with flat pricing across the whole window and automatic context caching on the official API

👁 Native vision

Multimodal image understanding built into the base model rather than bolted on - a first for the Kimi line

🔌 Full agentic API surface

Tool calling, required tool choice, dynamic tool loading, strict JSON-schema structured output, and computer-use capabilities

💸 $3/$15 with $0.30 cached input

Mid-tier Western pricing with a very cheap cached-input tier - roughly in line with Claude Sonnet 5's standard rate

🌐 Everywhere on day one

Available through kimi.com, Kimi mobile apps, Kimi Work 3.1+, Kimi Code, the official API, and OpenRouter immediately

The honest take

✓ What works

  • Largest open-weight model ever released, with a scheduled weights release
  • Native vision and 1M context in the base model
  • Cached input at $0.30/1M makes long repeated contexts cheap
  • OpenAI-SDK-compatible API drops integration cost to near zero

✗ What doesn't

  • 2.8T parameters need serious hardware to self-host even after weights land
  • API is served from China - a compliance consideration for some enterprises
  • Priced above DeepSeek-class open alternatives

Verdict

K3 is Moonshot's comeback card and the most credible open-source challenger to closed frontier models in mid-2026. If weights landed as scheduled, it is the self-host path to near-frontier capability; via API it is a strong Sonnet-class alternative with an unusually cheap cache tier.
