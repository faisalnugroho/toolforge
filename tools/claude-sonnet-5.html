Sonnet 5 makes Opus-class agentic work a daily-driver price

Released July 1, 2026, Claude Sonnet 5 is Anthropic's most agentic Sonnet yet - built for multi-step coding, tool use, web and search work, and sustained computer-use tasks. It became the default model for Claude Free and Pro plans on day one, ships in Claude Code and the Platform API as claude-sonnet-5, and in August 2026 Anthropic made its introductory $2/$10 per-million-token pricing permanent, cancelling the planned step-up to $3/$15.

Who it's for: Developers living in Claude Code, teams doing high-volume agentic work, and anyone on a Claude plan who wants near-Opus quality as the default.

Key features

🧠 Most agentic Sonnet yet

Stronger agentic execution across multi-step coding, terminal use, and software-engineering benchmarks than Sonnet 4.6 - quality Anthropic places closer to Opus 4.8 than to the old Sonnet tier.

⚡ Tunable effort levels

Dial effort from low to extra-high per task; rate limits were raised across Chat, Cowork, Claude Code, and the Platform API to absorb the higher token usage.

💸 $2/$10 pricing made permanent

The introductory $2 input / $10 output per 1M tokens became the permanent rate in August 2026 - the planned $3/$15 standard pricing no longer applies.

📦 In Claude Code from day one

A first-class coding-agent model: improved multi-step coding and terminal performance make it the default engine for Claude Code workflows.

🌐 Default on Free and Pro

Available across all plans on launch day - default for Free and Pro, with Max, Team, and Enterprise access and higher rate limits throughout.

🔁 1M-token context

A 1M-token context window for whole-project work - full repos, long documents, and cross-session agent memory without splitting inputs.

The honest take

✓ What works

  • $2/$10 intro pricing made permanent in August 2026
  • Real gains over Sonnet 4.6 on multi-step coding, terminal, and SWE benchmarks
  • Default on Free and Pro - no plan change needed to try it
  • Tunable effort levels with raised rate limits across every Claude surface

✗ What doesn't

  • New tokenizer maps the same input to roughly 1.0x-1.35x more tokens depending on content
  • Still generally below Opus 4.8 and Opus 5 on the hardest accuracy-sensitive passes
  • Extra-high effort levels burn tokens quickly

Verdict

The best value in the Claude lineup right now: near-frontier agentic capability at half the old Sonnet-standard price, in Claude Code from day one. If your work is iterative coding and agent loops, Sonnet 5 is the default; escalate to Opus only when a wrong final answer costs more than the token delta.
