Qwen3.8-27B: a 27B open model that beats 10x-bigger flagships on agentic work

Qwen3.8-27B is Alibaba's dense, open-weight vision-language model released August 14, 2026 under Apache 2.0 — 27B parameters (28B with vision encoder), a hybrid architecture of 48 Gated DeltaNet linear-attention layers plus 16 full-attention layers, and a native 262,144-token context window extendable to 1M via YaRN. Qwen's claim is capability-per-parameter: it outperforms the closed Qwen3.7-Plus overall and posts numbers that beat models roughly ten times its size on real-world coding and office workflows. On Qwen's own cards it scores 61.7 on SWE-bench Pro (vs 53.4 for Claude Opus 4.6 Max), 84.3 on OSWorld-Verified, 89.2 on GPQA Diamond, and a 217% jump on DeepSWE 1.1 (42.2) versus the previous 27B.

Who it's for: Developers who want frontier-adjacent agentic coding running locally on a single 24GB GPU, teams fine-tuning on top of open weights, and anyone building computer-use or office-workflow agents without per-token API bills.

Key features

🏋️ Runs on one consumer GPU

At 4-bit quantization Qwen3.8-27B fits on a single 24 GB card — frontier-adjacent agentic coding with zero API spend and full data locality.

💻 Agentic coding that punches up

61.7 SWE-bench Pro, 79.0 QwenSWEBench, 42.2 DeepSWE 1.1 and 73.0 Terminal-Bench 2.1 — it beats Opus 4.6 Max on the SWE-bench Pro and LiveCodeBench rows in Qwen's comparison table.

🖥️ Computer-use agent

84.3 on OSWorld-Verified (vs 73.3 for Qwen3.7-Plus) — desktop and mobile control as a first-class capability, not a bolt-on.

👁️ Native multimodal loop

Vision is part of the execution loop rather than just an input channel: 94.6 MathVision with CI, 38.6 SWE-MM multimodal software engineering, 62.9 Vision2Web.

📐 Hybrid linear attention

48 Gated DeltaNet layers + 16 full-attention layers keep long-context quality while taming memory — the architecture that makes 262K native (1M via YaRN) practical at this size.

🧩 Apache 2.0 ecosystem play

Qwen derivatives on Hugging Face have passed 151K — 2.6x Meta's footprint — so fine-tunes, adapters and tooling already exist for most niches.

The honest take

✓ What works

  • Beats models ~10x its size on agentic coding and office benchmarks (Qwen-reported)
  • Single 24GB GPU at 4-bit — genuinely laptop-class for this capability tier
  • Apache 2.0 with a 151K-derivative ecosystem on Hugging Face
  • Native multimodal: text, image and video input with vision in the agent loop
  • 262K native context, extendable to 1M with YaRN

✗ What doesn't

  • All headline numbers are vendor-run — no independent reproduction at launch
  • Trails frontier models on knowledge-heavy reasoning (Humanity's Last Exam 30.8, behind Opus on GPQA/Terminal-Bench)
  • Dense 27B full-precision needs more than 24GB — quantization is doing real work
  • Weights are the free part; hosted convenience costs ~$0.45/$3.20 per 1M on OpenRouter

Verdict

Qwen3.8-27B is probably the open-weight model to beat in the ~30B class. The agentic-coding and computer-use numbers are wild for something that runs on one gaming GPU, and the Apache 2.0 license plus the 151K-strong derivative ecosystem make it the practical choice for local agents. Treat the vendor-run table as a ceiling, not a floor — but even discounted, a 27B model beating Opus 4.6 Max's SWE-bench Pro row changes what 'small model' means.
