The honest take

Docling is IBM's open-source document AI library that parses PDFs, DOCX, and other formats into clean, structured output. Unlike cloud-based parsers, Docling runs entirely on your machine — no data leaves your network. It uses a pipeline of vision models, layout detection, and table recognition to produce high-quality markdown and JSON. For teams that need document parsing without sending sensitive data to third-party APIs, Docling is the answer.

Who it's for: Enterprise teams, privacy-conscious developers, and anyone building document processing pipelines that can't send data to external APIs. Self-hosted by design.

Key features

Local Fully self-hosted

Runs on your machine or servers. No data leaves your network. Perfect for sensitive documents.

Pipeline Multi-stage pipeline

Layout detection → OCR → table extraction → markdown conversion. Each stage is configurable.

Format Multiple output formats

Markdown, JSON, HTML. Choose the format that fits your downstream pipeline.

Vision Vision-model powered

Uses computer vision for layout understanding. Handles scanned docs, complex tables, and multi-column layouts.

Pros and cons

✓ What works

  • 100% local — no data leaves your machine
  • MIT licensed, no vendor lock-in
  • Excellent table extraction
  • Active IBM research backing

✗ What doesn't

  • Requires GPU for good performance
  • Setup is more complex than cloud APIs
  • Document types are limited vs. LlamaParse
  • Smaller community than commercial alternatives

Verdict

Docling is the go-to document parser for teams that can't use cloud APIs. If data privacy matters (healthcare, legal, finance), Docling gives you LlamaParse-level parsing without sending a single byte externally. The trade-off is setup complexity, but for enterprise use cases, it's worth it.
