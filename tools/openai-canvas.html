ChatGPT stops being a chat and becomes an editor

ChatGPT Canvas opens a side-by-side panel next to the conversation so you and the model can edit the same document or codebase together. Instead of copying output out of chat, you highlight inline, ask for a targeted rewrite, or run Python directly in the canvas. It is the single biggest UX change to ChatGPT since launch and the feature that made it viable for long-form writing and real coding sessions.

Who it's for: Anyone drafting long-form content, refactoring code, or iterating on a document where copy-paste between chat and editor was the bottleneck.

Key features

E Inline editing

Highlight any passage and ask for a rewrite, tone change, or expansion without losing the rest of the doc.

C Code runner

Python executes directly in the canvas with visible output -- iterate on scripts without leaving the tab.

V Version history

Roll back to any earlier version of the document with one click.

S Slash shortcuts

/suggest edits, /adjust length, /change reading level -- structured edits without re-prompting.

D Doc + code modes

One surface handles prose, Markdown, and executable code with the same editing grammar.

R Real-time collab

Share a canvas link so a teammate can watch or edit alongside the model.

The honest take

✓ What works

  • Kills the copy-paste loop between AI and editor entirely
  • Inline targeted rewrites preserve surrounding context
  • Code-canvas executes Python and shows errors inline
  • Free tier includes a useful daily quota
  • Feels like Notion AI but with GPT-class reasoning

✗ What doesn't

  • Only available inside ChatGPT -- no standalone app
  • Long documents still get slow on very large canvases
  • No Git import yet -- paste code in manually
  • A few structured-edit actions are paywalled behind Plus

Verdict

If you already pay for ChatGPT Plus, this is the feature that justifies it. For writing and code iteration inside one surface, nothing else in OpenAI's lineup comes close. Teams that live in Google Docs will still prefer Gemini's Workspace integration; everyone else should try the canvas first.
