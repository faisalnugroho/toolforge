The quality-per-dollar leader among arena-grade TTS APIs

Simba 3.2 is the developer API face of Speechify’s Simba voice family: you POST text with the model field set to simba-3.2 and get back synthesized speech either as a complete file or a low-latency stream that starts arriving as it generates. On the independent Artificial Analysis Text-to-Speech Arena it sits in the top cluster — an Elo of 1,227 that lands inside the confidence interval of Alibaba’s Qwen-Audio-3.0-TTS-Plus at 2.8x the price — with the lowest time-to-first-byte in the Simba family at under 300ms. It shapes emotion at the prosody level rather than only at the voice level, supports SSML prosody markup, and moves between Simba variants with a model-field change. The scope trade-off is deliberate: it is English-first at launch, it is an API you build around rather than a finished workflow, and it does one thing — synthesize speech. Multilingual needs route to simba-3.0 (English plus German, Spanish, French, Italian, Brazilian Portuguese), while the legacy Simba 1.6 pair (simba-english, simba-multilingual, 30+ locales, 1,500-voice catalog, zero-shot cloning) retires from API version 2026-09-21 and switches off on 2026-11-21.

Who it's for: Developers building voice agents, narration, accessibility, and reading features who want arena-grade English synthesis at production-friendly per-character pricing.

Key features

🎤 Arena-top English voice

Elo 1,227 on the Artificial Analysis TTS Arena — inside the confidence interval of Qwen-Audio-3.0-TTS-Plus at 2.8x the price — with blind-listener quality that holds up in production.

⚡ Under 300ms first byte

Lowest time-to-first-byte in the Simba family, streaming-native: speech starts arriving in chunks as the model generates, built for live conversational products.

🎬 Prosody-level emotion

Fine-grained emotional control and SSML prosody markup — steer tone, pacing, and emphasis per utterance instead of picking a static voice preset.

🔗 Unified Simba API

One endpoint across the family: moving between Simba 3.2 and multilingual Simba 3.0 is a model-field change, with first-party TypeScript and Python SDKs.

The honest take

✓ What works

  • From $6 per 1M characters — the cheapest arena-cluster voice in production
  • Blind-listener quality statistically level with models costing nearly 3x more
  • Streaming with sub-300ms time-to-first-byte for real-time agents
  • First-party Python and TypeScript SDKs plus a unified API across the Simba family

✗ What doesn't

  • English-first at launch — multilingual work routes to Simba 3.0’s six locales
  • API-only product: no finished studio workflow for non-developers
  • Synthesizes speech and nothing else — no dubbing, cloning marketplace, or sound effects
  • Legacy Simba 1.6 retirement (2026-09-21 API / 2026-11-21 shutoff) forces migration planning

Verdict

Simba 3.2 is the quality-per-dollar pick of the 2026 TTS field: arena-top English synthesis at $6 per 1M characters, streaming-native with sub-300ms first audio, and emotion control that operates at the prosody level. Build around it as a speech endpoint, not a platform — pair it with your own pipeline for anything beyond synthesis, and keep the simba-3.0 model field ready for the six-locale multilingual cases the 3.2 model does not cover.
