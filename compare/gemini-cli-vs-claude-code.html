The verdict

Choose Gemini CLI when free-tier budget, an Apache-2.0 open-source codebase, Google Search grounding, or a huge context window is the priority — students and tinkerers get a capable terminal agent at $0. Choose Claude Code when output quality on large refactors and agentic multi-step work matters more than price. Many teams run both: Gemini CLI for routine volume, Claude Code for hard design and security-sensitive changes.

Winner: Depends — budget: Gemini CLI; quality on complex code: Claude Code
