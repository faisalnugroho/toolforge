The verdict

Choose Zed if raw editor speed, open source, and agent freedom matter: the editor, Zeta model, and Agent Client Protocol are open source, and Personal ($0) allows unlimited use of your own API keys or external agents such as Claude Agent or Codex CLI over ACP. Choose Cursor for the most mature AI-first IDE with the largest community, VSCode-compatible extensions, and integrated multi-file agent flows. Speed purists pick Zed; ecosystem buyers pick Cursor.

Winner: Depends — speed + openness: Zed; ecosystem + maturity: Cursor
