The verdict

Identical price makes this a clean generational call. Opus 4.8's upgrades are structural - 1M-token context default versus 4.7's smaller window, 128K max output, mid-conversation system messages without beta headers, and the Claude Code Workflows primitive that fans one plan out to hundreds of parallel subagents. Benchmarks moved too: SWE-bench Pro 69.2% and OSWorld-Verified 83.4% at 4.8's launch led GPT-5.5 and Gemini 3.1 Pro. Six weeks apart at the same price, there is no scenario where a new build should pick 4.7 over 4.8 - pinned 4.7 deployments simply have no forced migration pressure.

Winner: Opus 4.8, outright, at the same price.
